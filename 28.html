Câu 28 – DOM xử lý sự kiện nhấn nút Style

Khi người dùng nhấn nút Style, đoạn văn bản bên dưới sẽ đổi fontSize, fontFamily và color.

Đoạn văn bản

JavaScript Exercises - w3resource

Style hiện tại: mặc định của trình duyệt.

Tùy chọn style

Mã JavaScript xử lý

function js_style() {
  var p = document.getElementById('text');
  p.style.fontSize   = size   + 'px';
  p.style.fontFamily = family;
  p.style.color      = color;
}

Cách hoạt động

  1. Nút #jsstyle có thuộc tính onclick="js_style()", nên hàm chạy mỗi lần nhấn.
  2. document.getElementById('text') lấy phần tử đoạn văn <p id='text'>.
  3. Giá trị cỡ chữ, phông chữ, màu được đọc từ các ô nhập.
  4. Gán vào style.fontSize, style.fontFamily, style.color để đổi giao diện ngay lập tức.
